# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

The short version. Be decent to people. Assume the person on the other end is trying. Criticise work rather than people, and criticise it with evidence, which in this repository usually means a measurement.

There is one project specific rule worth stating out loud, because the subject invites it. A lot of what is written about the BEAM is folklore repeated confidently, and correcting folklore is most of what this project does. Do that with a citation and a reproduction, not with a tone. If somebody arrives believing the reduction budget is 2000, they believed a conference talk, and the useful response is the file and the line, not a lecture.

Reports go to the address in the repository profile. They are read by the maintainers, kept private, and answered within five working days. If a report concerns a maintainer, say so and it will be handled by somebody else.
